HOW IT WORKS

세 단계면 끝납니다.

어려운 설정이나 설치 없이, 파일을 여는 순간부터 저장까지 한 흐름으로 이어집니다.

STEP 01

파일 열기

Markdown 파일을 화면에 끌어놓거나 내 컴퓨터에서 선택합니다.

STEP 02

내용 확인

원문과 읽기 화면을 나란히 보며 필요한 부분만 간단히 수정합니다.

STEP 03

원하는 형식으로 저장

PDF·HTML·Word 중 하나를 선택해 내 컴퓨터에 저장합니다.

PRIVACY BY DESIGN

문서는 먼저
사용자의 것입니다.

서버 저장 없음기본 모드에서는 문서 원문을 서버로 전송하거나 저장하지 않습니다.
사용자가 선택하는 임시 저장최근 문서 복구 기능은 동의를 받은 뒤 이 브라우저 안에서만 작동합니다.
언제든 데이터 삭제이 기기에 남은 임시 문서와 설정을 직접 삭제할 수 있도록 구성합니다.

SUPPORT

자주 묻는 질문

어떤 파일을 열 수 있나요?

`.md`, `.markdown`, `.txt` 형식을 지원하며 MVP에서는 최대 20MB까지 열 수 있습니다.

내 문서가 서버로 올라가나요?

현재 기본 기능은 브라우저 내부에서 처리합니다. 향후 클라우드 기능을 추가하면 별도 동의와 개인정보 안내를 제공합니다.

Word 변환 시 모든 서식이 유지되나요?

제목, 목록, 표, 이미지 등 주요 서식을 지원합니다. 복잡한 확장 문법은 일부 다르게 표시될 수 있습니다.

모바일에서도 사용할 수 있나요?

모바일에서는 미리보기와 내보내기를 우선 지원하고, 원문 편집은 데스크톱 환경을 권장합니다.
